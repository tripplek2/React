## Personal Blog
This is a simple react blog using components and props.it displays blog information and a list of articles.

## Features
1.Component structure.
2.Dynamic updates.
3.Clean and simple UI.

## Technologies used
1.Javascript.
2.Jsx.
3.React.

## How to run
1.Install install.
2.npm start and then open in the browser: http://localhost:5173/

## Component structure 
App(Parent)
*Header(Child)
*About(Child)
*Articlelist(Child)
*Article(Grandchild)

## Testing 
Run-npm test
